# Hookline detection rules

_Generated by `npm run rules:doc` from `extension/src/shared/ruleRegistry.ts` — Hookline 2.0.0, ruleset fingerprint `c41cfd80`. Do not edit by hand._

## Scoring

- Each rule has a **weight** (points at *high* severity). Severity factors: high 1, medium 0.5, low 0.25.
- Rules belong to a **group**; only the strongest item per group counts, and groups add up. Score = min(100, Σ group maxima).
- Verdict: **high risk** ≥ 50, **suspicious** ≥ 20, otherwise safe.
- Category: the scam category with the most points (≥ 20) among non-"general" rules, if the verdict isn't safe; otherwise "None detected".
- **Allow-list** (Tranco K9YYW top 10000 (9846 registrable domains; user-content hosts and shorteners excluded)): rules marked "AL" are ignored on allow-listed domains.
